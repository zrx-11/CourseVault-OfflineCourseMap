前置关系即学习顺序。阶段 0 是所有人都值得先打的数学地基；阶段 1 是概率统计与信息论的延伸；阶段 2 是计算机系统核心；阶段 3 起按兴趣分岔，各方向内部严格按箭头顺序推进。

01

数学地基：分析 · 代数 · 测度 · 概率 · 优化

这是整张地图的地基。建议顺序：实分析 → 代数 → 测度论 → 概率论 → 凸优化，前四门是严格证明训练，凸优化是通向工程、统计、经济学的枢纽课。

MIT 18.100
MIT · Real Analysis
分析
实分析 Real Analysis
本科高年级 / 研一 · Baby Rudin 配套

极限、收敛、度量空间、紧致性、连续性与一致连续、Riemann 积分的严格化。整门课就是「把直觉变成 ε-δ 证明」的训练，是所有后续严格数学的第一道关。

前置：微积分、线性代数、初等证明经验 通向：测度论、概率论、泛函、拓扑
本地资料 MIT 学生原版 LaTeX 逐讲笔记 PDF · MIT OCW 完整课程包（讲义+作业） rmwu 课堂笔记 PDF 与 OCW 官方课程资料，纯本地可读。
MIT 18.701
MIT · Algebra I
代数
抽象代数 Algebra I
研究生代数入门标准课

群、环、域三大结构的系统展开：商群、同构定理、多项式环、域的扩张与 Galois 理论的引子。证明导向，与实分析并行学效果最佳。

前置：线性代数 通向：代数拓扑、数论、现代密码学（6.875 的数学底座）
MATH 210
Stanford · Measure Theory
测度
测度论 Measure Theory
实分析的延续，概率论的前置

σ-代数、Lebesgue 测度与积分、收敛定理、乘积测度与 Fubini。Lebesgue 积分取代 Riemann 积分后，极限与积分才能自由交换——这是现代概率、统计、泛函分析的共同地基。

前置：MIT 18.100 / 等价实分析 通向：STAT 210、随机过程、泛函分析
STAT 210
Berkeley · Probability Theory
概率
概率论（研究生）Probability Theory
基于测度论的严格概率，研究生概率标准

概率空间、随机变量、期望、条件期望、大数定律与中心极限定理的严格证明。本科概率是算题，这门课才真正建立概率的数学结构。

前置：测度论（MATH 210） 通向：随机过程、金融数学、信息论、统计力学
EE 364A
Stanford · Convex Optimization
优化
凸优化 Convex Optimization（Boyd）
全地图最推荐的一门枢纽课 · 理论推导 + 数值编程作业

凸集、凸函数、对偶理论、KKT 条件、内点法。Boyd 的课程结构完美：证明跟着直觉走，编程作业用 CVXPY 把理论落地。工程、统计、经济、机器学习四大学科的共用工具。

前置：线性代数 + 基础分析（不需测度论） 通向：控制、计量、金融、机器学习

自学工具箱：笔记转 HTML、LaTeX 渲染与搜索

GitHub 笔记仓库多数是 Markdown / LaTeX 源码。下面四个工具解决「笔记怎么读、公式怎么渲染、仓库怎么找」三类问题。

本地 HTML + LaTeX 渲染（KaTeX）

本地 file:// 打开 HTML 渲染不了公式，通常因为 CDN 脚本被拦或字体加载受限。最稳的方案是起本地服务：python -m http.server 8000，再访问 http://127.0.0.1:8000。离线场景则下载 KaTeX 完整包，用相对路径引入 katex.min.css 与 auto-render.min.js，注意 fonts 目录不能移动。

mdbook：Markdown 笔记一键变站点

克隆的笔记仓库原生是 Markdown，可用 mdbook 把整套笔记导出成静态 HTML 站点，配合 KaTeX 渲染公式，本地 Edge 直接打开浏览，结构最接近原课程章节。

pandoc：LaTeX 批量转 HTML

仓库自带 .tex 时，用 pandoc notes.tex -o notes.html --katex 一键转成带 KaTeX 公式的 HTML，公式在本地也能渲染。

GitHub 搜索技巧

搜课程笔记用组合词：课程编号 + 关键词，例如 EE364a convex optimization notes 或 site:github.com "Lecture Notes" 18.100，再按 Markdown / LaTeX 语言筛选，优先选最近更新、含原版讲义结构的仓库。
